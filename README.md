# Solar Panel Field Service

Field service for solar and photovoltaic installers, built on Expodo Field Service.

Log each array, its panels and inverter, battery storage and grid connection, follow
the job from install or breakdown to invoice, run performance and electrical safety
checks, and let customers track their service online.

Free, LGPL-3, for Odoo Community 17, 18, 19 and 20.
